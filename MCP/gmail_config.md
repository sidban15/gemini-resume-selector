# Gmail MCP Configuration

## Connection Details
- **MCP Server Name:** Gmail
- **Status:** (Pending/Connected)
- **Permissions Required:** `gmail.compose`, `gmail.send`, `gmail.readonly`

## Capabilities
- Drafting rejection emails based on `Reject` folder status.
- Drafting selection/next-step emails for `ShortListed` candidates.
- Drafting referral outreach for `Referred` candidates.

## Usage Notes
- Always use the templates defined in the `/TEMPLATES` folder.
- Ensure the candidate's name and the specific role from the `/JD` folder are correctly mapped.
